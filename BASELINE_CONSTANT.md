# Baseline / Constant First

**Ratified 2026-08-12 by Hans.** Scientific method. Not a new Law. Law X still caps at six.
This is Law II applied to treatments, not only to laws.

## In plain English

Before you change a word, a prompt, an arm, or a model, write the number you get when you change nothing.

That number is the constant. If you do not have it, you are not measuring a gain. You are hunting.

## The rule

1. **Name the treatment.** The one thing you will vary.
2. **Run the same task with that thing off.** Same gold. Same model. Same scorer.
3. **Write that score first.** That is the baseline.
4. **Only then vary.** A word loop, an arm, a lexicon, a local model. Each treatment is compared to the constant, not to a story.

A printed positive control is not the constant. The control asks: can the instrument copy an answer that is already on the page. The constant asks: what does the instrument do with no treatment. You need both. Neither replaces the other.

You do not start the hunt until the constant is on disk.

## Why this is load-bearing

Exp 31b looked like a language result until the printed slots were named as copy. The untreated fact was the loud sentence we had already written. Without a constant, a favorite word can look like a win.

## Falsifier

A published "best word," "better arm," or "the model improved" with no untreated score beside it is not a result. Retract it or run the constant.

## Not this

Not a new commander verb. Not a phone change. Not a reason to skip a pre-reg. The pre-reg names the constant before the first treated call.

## Where it sits

- **Law II** (audit measurement before law) is the parent. This is the same demand at the treatment layer.
- **Training Architecture** Task / Conditions / Standards: the constant is a written condition. No constant, no standard.
- **No-self-grade:** the constant is a fact. It is not a vibe that the favorite would have beaten it.

## First use

Funkytown Exp 31 word-range (LB-P018). Object-word loop does not start until the untreated local-14B score is on disk.
